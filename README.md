# SmartOps 360

SmartOps 360 is a bilingual English/German building-maintenance workspace. It brings together maintenance jobs, planning, energy readings, cost tracking, dashboards and downloadable reports in one interface.

The project includes fictional example records across several sites and equipment types so visitors can explore the screens with realistic sample content. The examples are illustrative and do not represent live AUMA-TEC operations or confirmed company data.

The GitHub Pages edition is a browser-based demonstration. Changes are saved in the visitor's browser, so they remain available when that same browser returns to the page. Each visitor has a separate copy; edits are not shared between visitors or devices.
